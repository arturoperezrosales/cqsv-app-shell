# Instrucciones del repositorio

- `main` contiene la versión aprobada. Los cambios se proponen mediante rama y Pull Request.
- No hagas merge de un Pull Request; espera la aprobación de Arturo.
- No publiques credenciales, tokens, datos de clientes ni identificadores de proyectos Apps Script.
- Mantén `plugins/cqsv/` autocontenido. No apuntes clasp a proyectos productivos desde la plantilla.
- Valida con `claude plugin validate plugins/cqsv` y `claude plugin validate .` antes de enviar cambios al marketplace.
